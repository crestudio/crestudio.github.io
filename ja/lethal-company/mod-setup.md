# r2modman設置 {#install-r2modman}

1. https://thunderstore.io/package/ebkr/r2modman/ 接続
1. **Manual Downloadをクリック**してダウンロード
1. **r2modman設置**
1. 終わり

<br>

---

# 新しいコードでプロファイルを作成する {#add-profile}

1. **r2modman実行**
1. **リーサルカンパニーゲーム選択** <small>（Select Game）</small>
1. Import / Update クリック
1. **Import new profile クリック**
1. **From code クリック**
1. [お好きなモード](./mod-information/mod-list/)コードの貼り付け
1. プロファイル名入力
1. Createクリック
1. 新しく作成されたプロファイルをクリック
1. Select profile クリック
1. **Start moddedを押してリーサルカンパニーを実行**

<br>

# 既存のプロファイルを更新する {#update-profile}

1. **r2modman実行**
1. **リーサルカンパニーゲーム選択** <small>（Select Game）</small>
1. Import / Update クリック
1. **Update existing profile クリック**
1. **From code クリック**
1. [お好きなモード](./mod-information/mod-list/)コードの貼り付け
1. 上書きするプロファイルの選択
1. Update profile クリック
1. 更新したプロファイルをクリック
1. Select profile クリック
1. **Start moddedを押してリーサルカンパニーを実行**
