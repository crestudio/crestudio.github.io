# コマンド一覧 {#command}

Caramel Macchiato サーバーで使用できる各種コマンドの一覧です。<br>
使用するには `/` キーを押すとゲーム画面下部にチャット入力欄が表示されます。該当するコマンドを入力し、括弧がある場合は括弧内に適切な内容を入力して Enter キーを押すと実行できます。

## プレイヤー {#player}

| **コマンド** | **説明** |
| --- | --- |
| `/登録 <プレイヤー>`<br>`/addplayer <player>` | サーバーに該当するプレイヤーを登録します。ロビーサーバー専用です。 |
| `/時間`<br>`/time` | 現在プレイヤーがいるワールドの時間を確認します。 |
| `/メモ <テキスト>`<br>`/memo <text>` | メモを記録します。 |
| `/メモ`<br>`/memo` | 記録したメモを確認します。 |
| `/デスポイント`<br>`/deathpoint` | プレイヤーが最後に死亡した座標を確認します。 |
| `/リスポーン`<br>`/respawn` | プレイヤーが最後に死亡した座標へ移動します。 |

### リスポーン {#respawn}

- コマンドを使用するたびに、リスポーンに必要な金額が5,000円ずつ永久に増加します。
- 溶岩に落ちて死亡した場合、アイテムを強制的に復元します。
- 奈落に落ちて死亡した場合、アイテムのみ復元し、テレポートは行いません。

::: danger

ウォーデンに殺された場合、プラグインが対応していないため、最後の座標とアイテムが記録されない不具合があります。

:::

## 経済 {#economy}

| **コマンド** | **説明** |
| --- | --- |
| `/お金` `/残高`<br>`/check` `/money` `/balance` | プレイヤーが所持している資金を確認します。 |
| `/送金 <プレイヤー> <金額>`<br>`/pay <player> <price>` | 他のプレイヤーに指定した金額を送金します<br>プレイヤー名を入力しなかった場合は、周囲5ブロック以内のプレイヤーに送金します。 |
| `/順位` `/ランキング`<br>`/ranking` `/money top` | サーバー内の上位プレイヤーと所持金額を確認します。 |
| `/推薦`<br>`/recommand` | 自分を推薦したプレイヤーの人数を確認します。 |
| `/推薦 <プレイヤー>`<br>`/recommand <player>` | 他のプレイヤーを推薦します。<br>推薦すると、推薦したプレイヤー本人はオンライン状態のとき、ワールド保存時<small>(約10分)</small>に500円を受け取ります。<br>推薦されたプレイヤーは、推薦した本人がオンライン状態のとき、ワールド保存時に500円を受け取ります。 |
| `/政府保有金`<br>`/government` | 管理者の `Reonasa` と `マキアート` アカウントが保有している金額を表示します。 |
| `/iteminfo` | 現在手に持っているアイテムのChestShop用コードを確認します。 |

## 保護 {#protect}

| **コマンド** | **説明** |
| --- | --- |
| `/ロック` `/個人用` `/個人ロック`<br>`/lock` | 保護可能なブロックを個人用として保護します。 |
| `/ロック解除` `/ロック解除` `/ロックキャンセル`<br>`/unlock` | 保護されているブロックの個人保護を解除します。 |
| `/保護追加 <プレイヤー>`<br>`/ユーザー追加 <プレイヤー>`<br>`/cmodify <player>` | 保護されているブロックにユーザーを追加します。 |
| `/保護削除 <プレイヤー>`<br>`/ユーザー削除 <プレイヤー>`<br>`/cmodify -<player>` | 保護されているブロックからユーザーを削除します。 |
| `/公共ロック`<br>`/cpublic` | 誰でも使用できますが、撤去できないように保護します。 |
| `/寄付箱` `/郵便箱` `/ポスト`<br>`/cdonation` | 他のプレイヤーがアイテムを入れることだけできるように保護します。 |
| `/情報`<br>`/cinfo` | LWCで保護されているブロックの所有者を確認します。 |
| `/保護 <ブロック数>` | WorldGuardで保護するために必要な費用を計算します。 |
| `/ホッパー`<br>`/hopper` `/lwc flag hopper on` | ロックされているチェストでホッパーを使用できるようにします。 |

## VIP

| **コマンド** | **説明** |
| --- | --- |
| `/kick <player>` | 接続中のプレイヤーを強制的に退出させます。 |
| `/ban <player>` | 接続中のプレイヤーを永久にアクセス禁止にします。<br>永久BANは解除できません。 |
| `/tps` | 現在のサーバーのTPSを確認します。 |
| `/co inspect` `/co i` | 該当するブロックを誰が変更したか確認します。<br>設置されているブロックは左クリック、空気ブロックはブロックを設置することで関連するログを確認できます。<br>コンテナ<small>(Chestなど)</small>も確認できます。 |
| `/ショップ <ショップ名>`<br>`/shop <name>` | 現在地をショップとしてWebマップに登録します。 |
| `/町 <町名>`<br>`/town <name>` | 現在地を町としてWebマップに登録します。 |
| `/駅 <駅名>`<br>`/station <name>` | 現在地を駅としてWebマップに登録します。 |

::: info

Dynmapのマーカー機能を使用できます。<br>
コマンドの詳しい内容については、[Dynmap コマンドページ](https://dynmap.wiki.gg/wiki/Commands)をご確認ください。

:::

::: info

WorldGuardの調査機能を使用できます。<br>
該当するブロックがどの保護エリアに属しているか確認するには、革を手に持って右クリックしてください。

:::
