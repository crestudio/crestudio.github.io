# 커맨드 목록 {#command}

카라멜 마인크래프트 마인크래프트 서버에서 사용할 수 있는 각종 커맨드 목록 입니다<br>사용하기 위해서는 `/`키를 누르면 게임화면 아래에 채팅 입력창이 나옵니다, 해당 커맨드를 입력을 한 다음 괄호가 존재한다면 괄호 안의 내용은 적절한 내용을 넣은 후 엔터를 누르면 실행이 됩니다

## 플레이어 {#player}

| **커맨드** | **설명** |
| --- | --- |
| `/등록 <플레이어>`<br>`/addplayer <player>` | 서버에 해당 플레이어를 등록합니다, 로비 서버 전용입니다 |
| `/시간`<br>`/time` | 현재 플레이어가 위치한 월드의 시간을 확인합니다 |
| `/메모 <텍스트>`<br>`/memo <text>` | 메모를 기록합니다 |
| `/메모`<br>`/memo` | 메모를 확인합니다 |
| `/데스포인트`<br>`/deathpoint` | 플레이어가 마지막으로 죽은 좌표를 확인합니다 |
| `/리스폰`<br>`/respawn` | 플레이어가 마지막으로 죽은 좌표로 이동합니다 |

### 리스폰 {#respawn}

- 커맨드를 사용 할 때마다 5,000원 씩 영구히 리스폰에 필요한 금액이 증가합니다
- 용암에 빠져 죽은 경우, 아이템을 강제로 복구합니다
- 공허에 빠져 죽은 경우, 아이템만 복구하며 텔레포트는 하지 않습니다

::: danger

워든한테 죽은 경우 플러그인 미대응으로 마지막 좌표와 아이템이 기록되지 않는 버그가 있습니다

:::

## 경제 {#economy}

| **커맨드** | **설명** |
| --- | --- |
| `/돈` `/잔액`<br>`/check` `/money` `/balance` | 플레이어가 보유한 자금을 확인합니다 |
| `/송금 <플레이어> <금액>`<br>`/pay <player> <price>` | 다른 플레이어에게 지정한 금액을 송금합니다<br>만약 플레이어 이름을 입력하지 않으면 주변 5블럭 내의 플레이어에게 송금합니다 |
| `/순위` `/랭킹`<br>`/ranking` `/money top` | 서버 내 상위 플레이어 목록과 금액을 확인합니다 |
| `/추천`<br>`/recommand` | 몇 명이 자신을 추천을 하였는지 확인 합니다 |
| `/추천 <플레이어>`<br>`/recommand <player>` | 다른 플레이어를 추천합니다<br>추천을 하면 플레이어 본인은 온라인 상태일 때, 월드 저장시 마다<small>(약 10분)</small> 500원의 돈을 받습니다<br>추천을 받은 플레이어는 추천한 본인이 온라인 상태일 때, 월드 저장시 마다 500원의 돈을 받습니다 |
| `/정부보유금`<br>`/government` | 어드민 `리오나사`와 `마끼아또` 계정이 보유한 금액을 보여줍니다 |
| `/iteminfo` | 현재 손에 들고 있는 아이템의 ChestShop용 코드를 확인합니다 |
