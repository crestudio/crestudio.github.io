# r2modman 설치 {#install-r2modman}

1. https://thunderstore.io/package/ebkr/r2modman/ 접속
1. **Manual Download 클릭**하여 다운로드
1. **r2modman 설치**
1. 끝

<br>

---

# 새로운 코드로 프로필 만들기 {#add-profile}

1. **r2modman 실행**
1. **리썰 컴퍼니 게임 선택** <small>(Select Game)</small>
1. Import / Update 클릭
1. **Import new profile 클릭**
1. **From code 클릭**
1. [원하는 모드](./mod-information/mod-list/) 코드 붙여넣기
1. 프로파일 이름 입력
1. Create 클릭
1. 새로 생성된 프로파일 클릭
1. Select profile 클릭
1. **Start modded 눌러서 리썰 컴퍼니 실행**

<br>

---

# 기존 프로필 업데이트하기 {#update-profile}

1. **r2modman 실행**
1. **리썰 컴퍼니 게임 선택** <small>(Select Game)</small>
1. Import / Update 클릭
1. **Update existing profile 클릭**
1. **From code 클릭**
1. [원하는 모드](./mod-information/mod-list/) 코드 붙여넣기
1. 덮어쓰기 할 프로파일 선택
1. Update profile 클릭
1. 업데이트한 프로파일 클릭
1. Select profile 클릭
1. **Start modded 눌러서 리썰 컴퍼니 실행**
